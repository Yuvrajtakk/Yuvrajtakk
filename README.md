### Current technique

I'm a **B.Tech CSE-AI** student (batch 2023–2027, CGPA 8.5) at Anand International College of Engineering, Jaipur, currently running a remote **AI/ML internship at Watsoo Express Pvt. Ltd.** under Ankit Gupta.

```
short-term cursed technique : ML  →  Deep Learning  →  applied AI
long-term domain expansion  : AI × interactive / game systems
```

Right now that means building from-scratch ML implementations, benchmarking them against real datasets, and documenting the process like a lab notebook rather than a one-off notebook dump. The game-dev side (Unity, C#) runs in parallel as the second track that eventually merges with the AI one — intelligent, reactive interactive systems are the long-term target, not a side hobby.

**🔢 [mnist-digit-recognizer](https://github.com/Yuvrajtakk/mnist-digit-recognizer)**
