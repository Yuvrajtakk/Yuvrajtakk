### Current technique

I'm a **B.Tech CSE-AI** student (batch 2023–2027, CGPA 8.5) at Anand International College of Engineering, Jaipur. I just wrapped a remote **AI/ML internship at Watsoo Express Pvt. Ltd.**, where I went from from-scratch ML implementations to a production-style computer vision pipeline to a LangChain-based text-to-SQL chatbot.

```
short-term cursed technique : ML  →  Deep Learning  →  applied AI
long-term domain expansion  : AI × interactive / game systems
```

The game-dev side (Unity, C#) runs in parallel as the second track that eventually merges with the AI one — intelligent, reactive interactive systems are the long-term target, not a side hobby.

### What I built during the internship

<table>
<tr>
<td width="50%" valign="top">

**💬 [logistics_chatbot](https://github.com/Yuvrajtakk/logistics_chatbot)**

Logistics & Order Intelligence Chatbot — a text-to-SQL system answering natural language questions over the real Olist Brazilian e-commerce dataset (~100k orders, 9 relational tables). Built with LangChain (no agent toolkit, no LangGraph — a controlled retry loop instead), runtime-switchable between local (Ollama) and API (Groq/Gemini) LLMs, strictly read-only against the database.

`Python` `LangChain` `SQL` `Groq` `Gemini` `Ollama`

</td>
<td width="50%" valign="top">

**🚦 [Traffic_Analysis_YOLO_project](https://github.com/Yuvrajtakk/Traffic_Analysis_YOLO_project)**

Real-time traffic monitoring pipeline — custom-trained 10-class YOLOv8s detector + ByteTrack, running four live analytics modules (stationary vehicle, wrong-way, hazard, congestion) over RTSP, auto-saving annotated stills and clips per event. mAP50 0.721 on a self-built 10,329-image dataset.

`Python` `YOLOv8` `ByteTrack` `OpenCV` `PyTorch`

</td>
</tr>
<tr>
<td width="50%" valign="top">

**🔢 [mnist-digit-recognizer](https://github.com/Yuvrajtakk/mnist-digit-recognizer)**

MNIST digit recognition comparing 7 ML algorithms head-to-head — Linear Regression, Logistic Regression, KNN, Decision Tree, Random Forest, Naive Bayes, and SVM. SVM came out on top at **98.15% accuracy**, fully documented with a results comparison table.

`Python` `scikit-learn` `Jupyter` `Google Colab`

</td>
<td width="50%" valign="top">

**📓 [ml-internship](https://github.com/Yuvrajtakk/ml-internship)**

The learning-phase codebook — 9 structured Python files walking through ML algorithms from first principles through evaluation metrics, themed around a Watsoo Express truck-health use case. The foundation the MNIST comparison was built on top of.

`Python` `NumPy` `pandas`

</td>
</tr>
